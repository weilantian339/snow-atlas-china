# Snow Atlas China

Static HTML ski terrain atlas. Publish main branch root using GitHub Pages.

OpenStreetMap contributors (ODbL); community geometry is not officially verified. Terrain: AWS Open Data elevation-tiles-prod. MapLibre GL JS v5.0.0 (BSD-3-Clause).
Resort locations: OpenSkiData / OpenSkiMap.org, Skimap.org, OpenStreetMap contributors, Who's On First, Mapterhorn. Supplementary tree cover: ESA WorldCover 2021 v200 (CC BY 4.0), resampled near mapped pistes. Tree crowns and cable supports are illustrative.
